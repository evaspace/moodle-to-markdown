## Question 11
Type : divisibilité et division euclidienne (vrai/faux) · ECUE : HP (arithmétique)
Formules : $a \mid b \iff \exists k \in \mathbb{Z}, b = ka$ ; $a \mid b$ et $b \mid a \Rightarrow a = \pm b$ ; $a \mid b$, $a \mid c \Rightarrow a \mid bu + cv$ ; contre-exemple $2 \mid 4$, $4 \mid 4$, $8 \nmid 4$ ; $a \mid bc \not\Rightarrow a \mid b$ ou $a \mid c$ ($6 \mid 2 \times 3$) ; division euclidienne $0 \leqslant r < |b|$

Soient $a$ et $b$ deux entiers non nuls. On dit que $a$ divise $b$ si a. $\forall k \in \mathbb{Z}, a = bk$ ; b. $\exists k \in \mathbb{Z}, a = bk$ ; c. $\forall k \in \mathbb{Z}, b = ak$ ; d. $\exists k \in \mathbb{Z}, b = ak$ ; e. Aucune des autres réponses.

Réponse : d.

## Question 13
Type : divisibilité et division euclidienne (vrai/faux) · ECUE : HP (arithmétique)
Formules : $a \mid b \iff \exists k \in \mathbb{Z}, b = ka$ ; $a \mid b$ et $b \mid a \Rightarrow a = \pm b$ ; $a \mid b$, $a \mid c \Rightarrow a \mid bu + cv$ ; contre-exemple $2 \mid 4$, $4 \mid 4$, $8 \nmid 4$ ; $a \mid bc \not\Rightarrow a \mid b$ ou $a \mid c$ ($6 \mid 2 \times 3$) ; division euclidienne $0 \leqslant r < |b|$

Soit $(a, b, c) \in \mathbb{Z}^3$ tel que $a \mid b$ et $a \mid c$. a. $a \mid 2b - 3c$ ; b. $a^2 \mid b$ ; c. $b = c$ ; d. Aucune des autres réponses.

Réponse : a.

## Question 14
Type : division euclidienne dans $\mathbb{Z}$ · ECUE : HP (arithmétique)
Formules : $\exists!\,(q, r)$, $a = bq + r$, $0 \leqslant r < |b|$ ; ajuster : $a = bq + r = b(q+1) + (r - b)$ ; pour $-a$ : $-a = b(-q) - r = b(-q-1) + (b - r)$

$295 = 7 \times 41 + 8$. a. 8 est le reste de la division euclidienne de 295 par 7 ; b. 8 est le reste de la division euclidienne de 295 par 41 ; c. Aucune des autres réponses.

Réponse : b ($8 < 41$ mais $8 \geqslant 7$).

## Question 17
Type : Bézout (énoncé), diviseurs communs et PGCD · ECUE : HP (arithmétique)
Formules : Bézout : $a \wedge b = 1 \iff \exists (u,v), au + bv = 1$ ; corollaire : $\exists (u,v), au + bv = a \wedge b$ ; $d \mid a$ et $d \mid b \Rightarrow d \mid au + bv$ ; transitivité de $\mid$

$a$, $b$ entiers naturels non nuls. a. $a \mid a \wedge b$ ; b. $\exists d \in \mathbb{N}^*$, $d \mid a$, $d \mid b$ et $d > a \wedge b$ ; c. Si $a \wedge b = 1$, $a$ et $b$ sont des nombres premiers ; d. Aucune des autres réponses.

Réponse : d (c : premiers entre eux, pas premiers, ex. 12 et 35).

## Question 18
Type : Bézout (énoncé), diviseurs communs et PGCD · ECUE : HP (arithmétique)
Formules : Bézout : $a \wedge b = 1 \iff \exists (u,v), au + bv = 1$ ; corollaire : $\exists (u,v), au + bv = a \wedge b$ ; $d \mid a$ et $d \mid b \Rightarrow d \mid au + bv$ ; transitivité de $\mid$

D'après le théorème de Bézout : a. $a \wedge b = 1 \iff \exists (u, v) \in \mathbb{Z}^2, au + bv = 1$ ; b. $a \wedge b = 1 \iff au + bv = 1\ \exists (u, v)$ ; c. $a \wedge b = 1 \iff au + bv = 1$ ; d. Aucune n'est correctement écrite.

Réponse : a.

## Question 11
Type : propriétés des primitives · ECUE : APIS (intégrales) · Niveau : maths-s1-apis-integrales/2
Formules : $F$ primitive de $f$ $\iff F' = f$ ; primitives de $f$ : $F + c$, $c \in \mathbb{R}$ ; linéarité : $aF + bG$ primitive de $af + bg$ ; pas de règle pour le produit ni l'inverse ; toute fonction continue sur un intervalle admet une primitive

Soit $f$ continue sur $[0, 1]$. $F$ est une primitive de $f$ sur $[0, 1]$ si $F$ est dérivable sur $[0, 1]$ et a. $\forall t$, $f'(t) = F(t)$ ; b. $\forall t$, $F'(t) = f(t)$ ; c. $\forall t$, $f'(t) = F'(t)$ ; d. Aucune des autres réponses.

Réponse : b.

## Question 15
Type : propriétés des primitives · ECUE : APIS (intégrales) · Niveau : maths-s1-apis-integrales/2
Formules : $F$ primitive de $f$ $\iff F' = f$ ; primitives de $f$ : $F + c$, $c \in \mathbb{R}$ ; linéarité : $aF + bG$ primitive de $af + bg$ ; pas de règle pour le produit ni l'inverse ; toute fonction continue sur un intervalle admet une primitive

Soient $f$ continue sur $[0, 2]$, $F$ une primitive et $I = \int_0^2 f(t)\,dt$. Formules correctement écrites : a. $I = \int_0^2 [F(t)]_0^2\,dt$ ; b. $I = \int_0^2 F(t)\,dt$ ; c. $I = [F(t)]_0^2 = F(0) - F(2)$ ; d. Aucune formule n'est correctement écrite.

Réponse : d ($I = F(2) - F(0)$).

## Question 11
Type : limite de $q^n$ · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/1
Formules : $q > 1$ : $q^n \to +\infty$ ; $|q| < 1$ : $q^n \to 0$ ; $q = 1$ : 1 ; $q \leqslant -1$ : pas de limite

Soit $q \in \mathbb{R}$. La suite $(q^n)$ est a. croissante si $q > 1$ ; b. décroissante si $q > 1$ ; c. croissante si $q < 1$ ; d. décroissante si $q < 1$ ; e. Aucune des autres réponses.

Réponse : a.

## Question 12
Type : limite de $q^n$ · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/4
Formules : $q > 1$ : $q^n \to +\infty$ ; $|q| < 1$ : $q^n \to 0$ ; $q = 1$ : 1 ; $q \leqslant -1$ : pas de limite

$\lim q^n$ a. est égale à $+\infty$ si $q > 1$ ; b. est égale à 0 si $|q| < 1$ ; c. est égale à 0 si $q \leqslant -1$ ; d. Aucune des autres réponses.

Réponse : a et b.

## Question 13
Type : somme des termes d'une suite géométrique · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/1
Formules : $\sum_{k=0}^{n} q^k = \frac{1 - q^{n+1}}{1 - q}$ ($q \neq 1$) ; nombre de termes = $n + 1$

$q \neq 1$. a. $\sum_{k=0}^n q^k = \frac{1 - q^n}{1 - q}$ ; b. $= \frac{1 - q^{n+1}}{1 - q}$ ; c. $= \frac1{1 - q}$ ; d. Aucune des autres réponses.

Réponse : b.

## Question 14
Type : théorème de la limite monotone · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/8
Formules : croissante majorée $\Rightarrow$ convergente ; décroissante minorée $\Rightarrow$ convergente ; croissante non majorée $\Rightarrow +\infty$

$(u_n)$ telle que $\forall n$, $u_n \geqslant 3$. a. croissante $\Rightarrow$ converge ; b. décroissante $\Rightarrow$ converge ; c. bornée $\Rightarrow$ converge ; d. Aucune des autres réponses.

Réponse : b.

## Question 15
Type : suites adjacentes · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/9
Formules : adjacentes : $(u_n)$ croissante, $(v_n)$ décroissante, $v_n - u_n \to 0$ ; alors elles convergent vers la même limite ; $\frac1{(n+1)!} = \frac1{n!} \cdot \frac1{n+1}$

$(u_n)$ et $(v_n)$ adjacentes, $(v_n)$ croissante. a. $(u_n)$ croissante ; b. $(u_n)$ décroissante ; c. $(u_n)$ converge ; d. $(u_n)$ diverge ; e. Aucune des autres réponses.

Réponse : b et c.

## Question 16
Type : suites extraites · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/11
Formules : toute suite extraite d'une suite convergente converge vers la même limite ; $(u_{6n})$ extraite de $(u_{2n})$ et de $(u_{3n})$ ; $(u_{2n})$ et $(u_{2n+1})$ convergent vers $\ell$ $\Rightarrow (u_n) \to \ell$

Soient $(u_n)$ et $\ell \in \mathbb{R}$. a. $(u_n) \to \ell \Rightarrow (u_{2n}) \to \ell$ ; b. $(u_{2n}) \to \ell \Rightarrow (u_n) \to \ell$ ; c. Aucune des autres réponses.

Réponse : a.

## Question 17
Type : suites extraites · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/11
Formules : toute suite extraite d'une suite convergente converge vers la même limite ; $(u_{6n})$ extraite de $(u_{2n})$ et de $(u_{3n})$ ; $(u_{2n})$ et $(u_{2n+1})$ convergent vers $\ell$ $\Rightarrow (u_n) \to \ell$

$u_n = \frac{2n}{n + 3}$. a. $u_{2n+1} = \frac{2n + 1}{2n + 4}$ ; b. $u_{2n+1} = \frac{4n + 2}{2n + 4}$ ; c. $u_{2n+1} = \frac{2n + 3}{2n + 4}$ ; d. Aucune des autres réponses.

Réponse : b.

## Question 18
Type : limites usuelles de suites · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/4

Suite(s) divergente(s) : a. $((-1)^n)$ ; b. $\left(\frac1n\right)$ ; c. $(e^{-n})$ ; d. la suite constante égale à 1 ; e. Aucune des autres réponses.

## Question 19
Type : suite récurrente $u_{n+1} = f(u_n)$ · ECUE : APIS (suites) · Niveau : maths-s1-apis-suites/10
Formules : constante $\iff u_0 = f(u_0)$ ; tableau de variations via $f'$ ; $f$ croissante sur $I$ et $u_n \in I \Rightarrow f(a) < f(u_n) < f(b)$ (récurrence) ; signe de $u_{n+1} - u_n$ ; monotone bornée $\Rightarrow$ convergente ; $\ell = f(\ell)$

$f$ continue sur $\mathbb{R}$, $u_{n+1} = f(u_n)$. « Si $(u_n)$ converge vers un réel $\ell$ alors $\ell = f(\ell)$ » est a. fausse ; b. vraie.

Réponse : b.

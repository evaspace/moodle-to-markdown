## Question 11
Type : ensembles (appartenance, inclusion, union, intersection, produit, complémentaire) · ECUE : OBM · Niveau : maths-s1-obm/8
Formules : $x \in A$ ; $A \subset B$ ; $A \cup B$, $A \cap B$ ; $A \times B = \{(a, b), a \in A, b \in B\}$ ; complémentaire $\bar B = E \setminus B$ ; $B = [\![0, 7]\!]$

On veut définir des ensembles. Lequel est correctement écrit ? a. $E = \{1, 2$ ; b. $F = \{1, 3, 2\}$ ; c. $G = 1, 2$ ; d. $H = (1, 2)$ ; e. Aucune de ces expressions ne définit un ensemble.

Réponse : b.

## Question 15
Type : injectivité / surjectivité, composées · ECUE : OBM · Niveau : maths-s1-obm/10
Formules : injective : $f(x) = f(y) \Rightarrow x = y$, contre-exemple $f(a) = f(b)$ avec $a \neq b$ ; surjective : $\forall y, \exists x, f(x) = y$ ; $(f \circ g)(x) = f(g(x))$

Soient $E$, $F$ deux ensembles et $f : E \to F$. $f$ est injective si et seulement si
a. $\forall (x, x') \in E^2$, $x = x' \Rightarrow f(x) = f(x')$ ; b. $\forall (x, x') \in E^2$, $x \neq x' \Rightarrow f(x) \neq f(x')$ ; c. $\forall (x, x')$, $x = x'$ et $f(x) \neq f(x')$ ; d. $\forall (x, x')$, $x \neq x'$ et $f(x) = f(x')$ ; e. Aucune des autres réponses.

Réponse : b.

## Question 16

Formules : $f(A) = \{f(x), x \in A\}$ ; $f^{-1}(B) = \{x, f(x) \in B\}$ ; lire les valeurs prises (bornes ouvertes / fermées) ; $f(\mathbb{R})$ = ensemble des valeurs prises

Soit $f : \mathbb{R} \to \mathbb{R}$, $f(x) = x^2$. a. $f(\{0, 1\}) = [0, 1]$ ; b. $f^{-1}(\{4\}) = \{-16, 16\}$ ; c. $f^{-1}(\{-1\}) = \emptyset$ ; d. Aucune des autres réponses.

Réponse : c.

## Question 17
Type : injectivité / surjectivité, restriction · ECUE : OBM · Niveau : maths-s1-obm/10
Formules : injective $\iff$ toute droite horizontale coupe le graphe au plus une fois ; surjective sur $F$ $\iff$ tout $y \in F$ est atteint ; $(x-2)^2 - 1 \geqslant -1$ ; restreindre le départ à $[2, +\infty[$ rend injective, l'arrivée à $[-1, +\infty[$ rend surjective

Soient $I$ et $J$ deux sous-ensembles de $\mathbb{R}$ et $f : I \to J$, $x \mapsto x^2$. a. Si $I = J = \mathbb{R}$, $f$ est surjective ; b. Si $I = \mathbb{R}$ et $J = \mathbb{R}^+$, $f$ est surjective ; c. Si $I = \mathbb{N}$ et $J = \mathbb{N}$, $f$ est surjective ; d. Aucune des autres réponses.

Réponse : b (c faux : 2 n'est pas le carré d'un entier).

## Question 18
Type : cardinal d'une union, partition · ECUE : DP · Niveau : maths-s1-dp/1
Formules : $F \cap G = \emptyset \Rightarrow \mathrm{Card}(F \cup G) = \mathrm{Card}F + \mathrm{Card}G$ ; $A = (A \setminus B) \sqcup (A \cap B)$ ; $\mathrm{Card}(A \cup B) = \mathrm{Card}A + \mathrm{Card}B - \mathrm{Card}(A \cap B)$

Deux ensembles finis $A$ et $B$. a. $\mathrm{Card}(A \cap B) = \mathrm{Card}(A) \times \mathrm{Card}(B)$ ; b. $= \mathrm{Card}(A) + \mathrm{Card}(B)$ ; c. $= \mathrm{Card}(A) + \mathrm{Card}(B) - \mathrm{Card}(A \cup B)$ ; d. $= \mathrm{Card}(A \cup B) - \mathrm{Card}(A) - \mathrm{Card}(B)$ ; e. Aucune des autres réponses.

Réponse : c.

## Question 19
Type : dénombrement (p-listes, arrangements, anagrammes, parties) · ECUE : DP · Niveau : maths-s1-dp/3
Formules : $p$-listes (avec remise, ordre) : $n^p$ ; arrangements (sans remise, ordre) : $A_n^p = \frac{n!}{(n-p)!}$ ; permutations : $n!$ ; anagrammes avec lettres répétées : $\frac{n!}{k_1!k_2!\dots}$ ; nombre de parties d'un ensemble à $m$ éléments : $2^m$ ; principe multiplicatif

$E = \{0, 1, 2, 3, 4\}$, 3-uplets $(a, b, c) \in E^3$. a. Le nombre de 3-uplets d'éléments distincts est $3 \times 4 \times 5$ ; b. il est $5^3$ ; c. Le nombre de 3-uplets quelconques est $3 \times 4 \times 5$ ; d. il est $5^3$ ; e. Aucune des autres réponses.

Réponse : a et d.

## Question 20
Type : dénombrement (p-listes, arrangements, anagrammes, parties) · ECUE : DP · Niveau : maths-s1-dp/3
Formules : $p$-listes (avec remise, ordre) : $n^p$ ; arrangements (sans remise, ordre) : $A_n^p = \frac{n!}{(n-p)!}$ ; permutations : $n!$ ; anagrammes avec lettres répétées : $\frac{n!}{k_1!k_2!\dots}$ ; nombre de parties d'un ensemble à $m$ éléments : $2^m$ ; principe multiplicatif

a. Le nombre d'anagrammes du mot « MATH » est 4 ; b. il est $4!$ ; c. Le nombre d'anagrammes de « ASSEZ » est 5 ; d. il est $5!$ ; e. Aucune des autres réponses.

Réponse : b (« ASSEZ » : $\frac{5!}{2!} = 60$).

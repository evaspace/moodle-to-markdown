## Exercice (version 1)
Type : noyau, image, rang d'une application linéaire · ECUE : ALM · Niveau : maths-s2-alm/3
Formules : linéaire : $f(\lambda u + v) = \lambda f(u) + f(v)$ ; $\mathrm{Ker} f$ : résoudre $f(x) = 0$ ; théorème du rang $\dim E = \dim\mathrm{Ker} f + \mathrm{rg} f$ ; $\mathrm{rg} f = \dim F \Rightarrow \mathrm{Im} f = F$ (surjective) ; $\mathrm{Im} f = \mathrm{Vect}(f(e_1), \dots, f(e_n))$

a. $\mathrm{Ker}(f)=\mathrm{Vect}\big((-1,1,0), (0,0,1)\big)$, $\dim\mathrm{Ker}(f)=2$.
b. $\mathrm{Im}(f)=\mathrm{Vect}\big((2,1)\big)$ (engendrée par les images de la base canonique), $\dim\mathrm{Im}(f)=1$.
c. Injective : non, car $\mathrm{Ker}(f)\ne\{0\}$. Surjective : non, car $\dim\mathrm{Im}(f)=1<2$.
d. Théorème du rang : $\dim E=\dim\mathrm{Ker}(f)+\dim\mathrm{Im}(f)$. Ici $3=2+1$.

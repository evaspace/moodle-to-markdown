## Question 11
Type : trigonométrie (parité, signe de sin) · ECUE : APEF (fonctions)
Formules : $\sin(-x) = -\sin x$ (impaire), $\cos(-x) = \cos x$ (paire) ; $\sin \geqslant 0$ sur $[0, \pi]$, $\leqslant 0$ sur $[\pi, 2\pi]$

On considère la fonction $f : x \mapsto \sin(x)$. On a
a. $f$ est paire ; b. $f$ est impaire ; c. $\forall x \in [0, \pi]$, $0 \leqslant f(x) \leqslant 1$ ; d. $\forall x \in \left[\frac\pi2, \frac{3\pi}2\right]$, $0 \leqslant f(x) \leqslant 1$ ; e. Aucune des autres réponses.

Réponse : b et c.

## Question 12
Type : valeurs remarquables de cos et sin · ECUE : APEF (fonctions)
Formules : $\cos\frac\pi6 = \frac{\sqrt3}2$, $\cos\frac\pi4 = \frac{\sqrt2}2$, $\cos\frac\pi3 = \frac12$, $\cos\frac\pi2 = 0$ ; $\sin\frac\pi6 = \frac12$, $\sin\frac\pi3 = \frac{\sqrt3}2$, $\sin\frac\pi2 = 1$ ; $\cos(\pi - x) = -\cos x$

Cochez la (les) réponse(s) correcte(s).
a. $\cos\frac\pi3 = \frac{\sqrt3}2$ ; b. $\cos\frac{5\pi}6 = -\frac{\sqrt3}2$ ; c. $\sin\frac\pi2 = 0$ ; d. $\sin\frac\pi2 = 1$ ; e. Aucune des autres réponses.

Réponse : b et d.

## Question 13
Type : formules trigonométriques · ECUE : APEF (fonctions)
Formules : $\cos(\pi - x) = -\cos x$ ; $\cos(\pi + x) = -\cos x$ ; $\sin\left(\frac\pi2 - x\right) = \cos x$ ; $\cos^2 x + \sin^2 x = 1$

Soit $x \in \mathbb{R}$. Cochez la (les) réponse(s) correcte(s).
a. $\cos(\pi - x) = \cos(x)$ ; b. $\sin\left(\frac\pi2 - x\right) = \cos(x)$ ; c. $\cos(\pi + x) = \sin(x)$ ; d. $\cos(x) + \sin(x) = 1$ ; e. Aucune des autres réponses.

Réponse : b.

## Question 14

Formules : $\cos' = -\sin$ ; $\sin' = \cos$ ; $\tan' = 1 + \tan^2 = \frac1{\cos^2}$ ; $(x^n)' = nx^{n-1}$ ; $(e^x)' = e^x$ ; $(\ln x)' = \frac1x$

Cochez la (les) réponse(s) correcte(s).

Réponse : b et c.

## Question 15
Type : fonction tangente · ECUE : APEF (fonctions)
Formules : $\tan = \frac{\sin}{\cos}$, définie sur $\mathbb{R} \setminus \{\frac\pi2 + k\pi\}$ ; $\tan' = 1 + \tan^2 = \frac1{\cos^2}$

On considère la fonction $f : x \mapsto \tan(x)$. On a
a. $f$ est définie sur $\mathbb{R}$ ; b. là où elle est définie, $f(x) = \frac{\cos x}{\sin x}$ ; c. là où elle est dérivable, $f'(x) = 1 - \tan^2(x)$ ; d. là où elle est dérivable, $f'(x) = 1 + \tan(x)$ ; e. Aucune des autres réponses.

Réponse : e ($\tan = \frac{\sin}{\cos}$, $\tan' = 1 + \tan^2$).

## Question 16
Type : coefficient directeur d'une droite · ECUE : APEF (fonctions)
Formules : $m = \frac{f(b) - f(a)}{b - a} = \frac{y_B - y_A}{x_B - x_A}$

Soient $a$, $b$ deux réels distincts et $f$ une fonction définie sur $\mathbb{R}$. Soient $A$ et $B$ deux points de la courbe représentative de $f$ d'abscisses respectives $x_A = a$ et $x_B = b$. Le coefficient directeur de la droite $(AB)$ est
a. $m = \frac{f(a) + f(b)}{b - a}$ ; b. $m = \frac{f(b) - f(a)}{b + a}$ ; c. $m = \frac{f(b) - f(a)}{b - a}$ ; d. Aucune des autres réponses.

Réponse : c.

## Question 17
Type : continuité et dérivabilité · ECUE : APEF (fonctions) · Niveau : maths-s2-apef-fonctions/1
Formules : dérivable $\Rightarrow$ continue (réciproque fausse : $|x|$ en 0) ; continue en $a$ $\iff \lim_a f = f(a)$ ; tangente verticale : $\frac{f(x) - f(a)}{x - a} \to \pm\infty$, non dérivable

Soit $f$ une fonction définie sur $\mathbb{R}$ admettant une tangente verticale au point de la courbe représentative de $f$ d'abscisse 1. Alors $f$ n'est pas dérivable en 1. a. vrai ; b. faux.

Réponse : a.

## Question 18
Type : continuité et dérivabilité · ECUE : APEF (fonctions) · Niveau : maths-s2-apef-fonctions/1
Formules : dérivable $\Rightarrow$ continue (réciproque fausse : $|x|$ en 0) ; continue en $a$ $\iff \lim_a f = f(a)$ ; tangente verticale : $\frac{f(x) - f(a)}{x - a} \to \pm\infty$, non dérivable

La fonction $x \mapsto |x|$ a. est dérivable en 0 ; b. n'est pas dérivable en 0 ; c. est continue en 0 ; d. n'est pas continue en 0 ; e. Aucune des autres réponses.

Réponse : b et c.

## Question 19
Type : dériver une composée · ECUE : APIS (intégrales) · Niveau : maths-s1-apis-integrales/1
Formules : $(g \circ u)' = u' \times g' \circ u$ ; $(e^u)' = u'e^u$ ; $(\sqrt u)' = \frac{u'}{2\sqrt u}$ ; $(u^n)' = nu'u^{n-1}$ ; $(\ln u)' = \frac{u'}u$

Là où elles existent, on a
a. $\left(e^{-x^2}\right)' = e^{-2x}$ ; b. $\left(e^{-x^2}\right)' = -2xe^{-x^2}$ ; c. $\left(\sqrt{2x}\right)' = \frac1{\sqrt x}$ ; d. $\left(\sqrt{2x}\right)' = -\frac1{\sqrt{2x}}$ ; e. Aucune des autres réponses.

Réponse : b ($\left(\sqrt{2x}\right)' = \frac{1}{\sqrt{2x}}$).

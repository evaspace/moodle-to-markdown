## Question 11
Type : propriétés des primitives · ECUE : APIS (intégrales) · Niveau : maths-s1-apis-integrales/2
Formules : $F$ primitive de $f$ $\iff F' = f$ ; primitives de $f$ : $F + c$, $c \in \mathbb{R}$ ; linéarité : $aF + bG$ primitive de $af + bg$ ; pas de règle pour le produit ni l'inverse ; toute fonction continue sur un intervalle admet une primitive

Soient $f$ une fonction continue sur $I$ et $F$ une primitive de $f$ sur $I$. On a
a. $\forall t \in I$, $f'(t) = F(t)$ ; b. $\forall t \in I$, $F'(t) = f(t)$ ; c. $t \mapsto F(t) + 2$ est aussi une primitive de $f$ sur $I$ ; d. $t \mapsto 2F(t)$ est aussi une primitive de $f$ sur $I$ ; e. Aucune des autres réponses.

Réponse : b et c.

## Question 12
Type : propriétés des primitives · ECUE : APIS (intégrales) · Niveau : maths-s1-apis-integrales/2
Formules : $F$ primitive de $f$ $\iff F' = f$ ; primitives de $f$ : $F + c$, $c \in \mathbb{R}$ ; linéarité : $aF + bG$ primitive de $af + bg$ ; pas de règle pour le produit ni l'inverse ; toute fonction continue sur un intervalle admet une primitive

Soient $f$ et $g$ deux fonctions continues sur $I$, $F$ une primitive de $f$ et $G$ une primitive de $g$ sur $I$. On a
a. $2F + 3G$ est une primitive de $2f + 3g$ sur $I$ ; b. $F \times G$ est une primitive de $f \times g$ sur $I$ ; c. si $f$ et $F$ ne s'annulent pas sur $I$, $\frac1F$ est une primitive de $\frac1f$ sur $I$ ; d. Aucune des autres réponses.

Réponse : a.

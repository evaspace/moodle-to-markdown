## Question 11
Type : géométrie de l'espace (plans, droites, vecteurs) · ECUE : HP (géométrie, parcours PA)
Formules : $ax + by + cz + d = 0$ : plan de $\mathbb{R}^3$ ; $\{M, \overrightarrow{OM} = \alpha\vec u\}$ : droite vectorielle ; combinaison linéaire coordonnée par coordonnée ; $\vec u, \vec v$ colinéaires $\iff \exists k, \vec v = k\vec u$ (ou l'un nul)

Dans $\mathbb{R}^3$, l'équation $2x + y - 2z + 6 = 0$ correspond à l'équation a. d'une droite ; b. d'un plan ; c. d'un cercle ; d. Rien de ce qui précède.

Réponse : b.

## Question 14
Type : géométrie de l'espace (plans, droites, vecteurs) · ECUE : HP (géométrie, parcours PA)
Formules : $ax + by + cz + d = 0$ : plan de $\mathbb{R}^3$ ; $\{M, \overrightarrow{OM} = \alpha\vec u\}$ : droite vectorielle ; combinaison linéaire coordonnée par coordonnée ; $\vec u, \vec v$ colinéaires $\iff \exists k, \vec v = k\vec u$ (ou l'un nul)

Soient $\vec u = (1, 0, 2)$, $\vec v = (1, 3, 0)$ et $\vec w = (-4, 0, 8)$ dans $\mathbb{R}^3$. On a
a. $\vec u$ et $\vec v$ sont colinéaires ; b. $\vec u$ et $\vec v$ ne sont pas colinéaires ; c. $\vec u$ et $\vec w$ sont colinéaires ; d. $\vec u$ et $\vec w$ ne sont pas colinéaires.

Réponse : b et d ($-4\vec u = (-4, 0, -8) \neq \vec w$).

## Question 15

Formules : $i^2 = -1$ ; $\overline{a + ib} = a - ib$ ; $\frac{z}{w} = \frac{z\bar w}{|w|^2}$ ; $|a + ib| = \sqrt{a^2 + b^2}$ ; $\left|\frac zw\right| = \frac{|z|}{|w|}$ ; $|\bar z| = |z|$

On considère $z_1 = 2 - i$ et $z_2 = -1 + 3i$. On a a. $z_1 - z_2 = 3 - 4i$ ; b. $z_1 - z_2 = 1 + 2i$ ; c. $z_1 - z_2 = 3 + 2i$ ; d. Aucune des autres réponses.

Réponse : a.

## Question 18
Type : forme exponentielle, argument · ECUE : HP (nombres complexes, hors programme 2031)
Formules : $z = |z|e^{i\theta}$ ; $e^{i\theta}e^{i\varphi} = e^{i(\theta + \varphi)}$ ; $\frac{e^{i\theta}}{e^{i\varphi}} = e^{i(\theta - \varphi)}$ ; $(re^{i\theta})^n = r^ne^{in\theta}$ ; $-i = e^{-i\pi/2}$

Un argument du nombre complexe $z = -2i$ est a. 0 ; b. $\pi$ ; c. $\frac\pi2$ ; d. Aucune des autres réponses.

Réponse : d (un argument est $-\frac\pi2$).

## Question 20
Type : forme exponentielle, argument · ECUE : HP (nombres complexes, hors programme 2031)
Formules : $z = |z|e^{i\theta}$ ; $e^{i\theta}e^{i\varphi} = e^{i(\theta + \varphi)}$ ; $\frac{e^{i\theta}}{e^{i\varphi}} = e^{i(\theta - \varphi)}$ ; $(re^{i\theta})^n = r^ne^{in\theta}$ ; $-i = e^{-i\pi/2}$

Le nombre complexe $z = -1 + i$ est égal à a. $\sqrt2e^{i\frac\pi4}$ ; b. $\sqrt2e^{i\frac{3\pi}4}$ ; c. $\sqrt2e^{-i\frac\pi4}$ ; d. $\sqrt2e^{-i\frac{5\pi}4}$ ; e. Aucune des autres réponses.

Réponse : b et d ($-\frac{5\pi}4 \equiv \frac{3\pi}4\ [2\pi]$).

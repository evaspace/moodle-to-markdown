## Question 11
Type : vecteurs du plan, repère, combinaison linéaire · ECUE : HP (géométrie, parcours PA)
Formules : $(O\,;\,\vec u, \vec v)$ repère $\iff \vec u, \vec v$ non colinéaires $\iff \det(\vec u, \vec v) = xy' - x'y \neq 0$ ; $a\vec u + b\vec v = (ax + bx', ay + by')$

Soient $A(1, -2)$ et $B(-2, 3)$ deux points du plan. Le vecteur $\overrightarrow{AB}$ a pour coordonnées
a. $(-3, 1)$ ; b. $(-1, 1)$ ; c. $(3, -5)$ ; d. $(-3, 5)$ ; e. Aucune des autres réponses.

Réponse : d.

## Question 12
Type : vecteurs du plan, repère, combinaison linéaire · ECUE : HP (géométrie, parcours PA)
Formules : $(O\,;\,\vec u, \vec v)$ repère $\iff \vec u, \vec v$ non colinéaires $\iff \det(\vec u, \vec v) = xy' - x'y \neq 0$ ; $a\vec u + b\vec v = (ax + bx', ay + by')$

Soient $\vec u$ et $\vec v$ deux vecteurs non nuls du plan tels que $3\vec u - 2\vec v = \vec 0$. Alors
a. $\vec u$ et $\vec v$ sont colinéaires ; b. $\vec u$ et $\vec v$ ne sont pas colinéaires ; c. On ne peut rien dire.

Réponse : a.

## Question 13
Type : vecteurs du plan, repère, combinaison linéaire · ECUE : HP (géométrie, parcours PA)
Formules : $(O\,;\,\vec u, \vec v)$ repère $\iff \vec u, \vec v$ non colinéaires $\iff \det(\vec u, \vec v) = xy' - x'y \neq 0$ ; $a\vec u + b\vec v = (ax + bx', ay + by')$

On considère les vecteurs tracés sur un quadrillage : $A(1, 1)$, $B(5, 2)$, $C(1, -4)$, $D(4, -2)$, $E(-1, -2)$, $F(-5, -3)$ (segments $[AB]$, $[CD]$, $[EF]$).
a. $\overrightarrow{AB}$ et $\overrightarrow{CD}$ sont colinéaires ; b. $\overrightarrow{AB}$ et $\overrightarrow{EF}$ sont colinéaires ; c. $\overrightarrow{CD}$ et $\overrightarrow{EF}$ sont colinéaires ; d. Aucune des autres réponses.

Réponse : b ($\overrightarrow{AB} = (4, 1)$, $\overrightarrow{EF} = (-4, -1)$, $\overrightarrow{CD} = (3, 2)$).

## Question 14
Type : droites du plan (point, vecteur directeur, équation, parallélisme) · ECUE : HP (géométrie, parcours PA)
Formules : $D = \{M, \exists \alpha, \overrightarrow{AM} = \alpha\vec u\}$ ; $ax + by + c = 0$ a pour vecteur directeur $(-b, a)$ ; droite par l'origine : $y = mx$ ; droites parallèles $\iff$ vecteurs directeurs colinéaires

Soient $A$ et $B$ deux points distincts de $\mathbb{R}^2$ définissant la droite affine $(AB)$. On a
a. $(AB)$ est l'ensemble des points $M$ tels que $\overrightarrow{AB}$ et $\overrightarrow{AM}$ ne sont pas colinéaires ;
b. $(AB)$ est l'ensemble des points $M$ tels qu'il existe $\alpha \in \mathbb{R}$ tel que $\overrightarrow{AM} = \alpha\overrightarrow{AB}$ ;
c. $\overrightarrow{BA}$ est un vecteur directeur de la droite $(AB)$ ;
d. Aucune des autres réponses.

Réponse : b et c.

## Question 17
Type : droites du plan (point, vecteur directeur, équation, parallélisme) · ECUE : HP (géométrie, parcours PA)
Formules : $D = \{M, \exists \alpha, \overrightarrow{AM} = \alpha\vec u\}$ ; $ax + by + c = 0$ a pour vecteur directeur $(-b, a)$ ; droite par l'origine : $y = mx$ ; droites parallèles $\iff$ vecteurs directeurs colinéaires

Cochez la (les) bonne(s) réponse(s) :
a. La droite d'équation $x = 1$ est une droite vectorielle ; b. La droite d'équation $y = 1$ est une droite vectorielle ; c. La droite d'équation $x = 0$ est une droite vectorielle ; d. La droite d'équation $2x + y = 1$ est une droite vectorielle ; e. Aucune des autres réponses.

## Question 18
Type : droites du plan (point, vecteur directeur, équation, parallélisme) · ECUE : HP (géométrie, parcours PA)

a. $\mathcal{D}$ a pour équation $y = 2x$ ; b. $\mathcal{D}$ a pour équation $2x - y + 3 = 0$ ; c. $\mathcal{D}$ a pour équation $x - 2y + 3 = 0$ ; d. Aucune des autres réponses.

## Question 19
Type : vecteurs du plan, repère, combinaison linéaire · ECUE : HP (géométrie, parcours PA)
Formules : $(O\,;\,\vec u, \vec v)$ repère $\iff \vec u, \vec v$ non colinéaires $\iff \det(\vec u, \vec v) = xy' - x'y \neq 0$ ; $a\vec u + b\vec v = (ax + bx', ay + by')$

Soient $\vec u = (1, 1)$ et $\vec v = (1, -1)$ deux vecteurs non nuls du plan tels que $(O, \vec u, \vec v)$ soit un repère du plan. Soit $\vec X = 2\vec u - 3\vec v$.
a. $(2, -3)$ sont les coordonnées de $\vec X$ dans le repère $(O, \vec u, \vec v)$ ;
b. $(2, -3)$ sont les coordonnées de $\vec X$ dans le repère $(O, \vec\imath, \vec\jmath)$ ;
c. $(-1, 5)$ sont les coordonnées de $\vec X$ dans le repère $(O, \vec u, \vec v)$ ;
d. $(-1, 5)$ sont les coordonnées de $\vec X$ dans le repère $(O, \vec\imath, \vec\jmath)$ ;
e. Aucune des autres réponses.

Réponse : a et d ($2(1,1) - 3(1,-1) = (-1, 5)$).

## Question 20
Type : vecteurs du plan, repère, combinaison linéaire · ECUE : HP (géométrie, parcours PA)
Formules : $(O\,;\,\vec u, \vec v)$ repère $\iff \vec u, \vec v$ non colinéaires $\iff \det(\vec u, \vec v) = xy' - x'y \neq 0$ ; $a\vec u + b\vec v = (ax + bx', ay + by')$

Soient $\vec u$ et $\vec v$ deux vecteurs non nuls du plan. À quelle condition $(O, \vec u, \vec v)$ forme-t-il un nouveau repère du plan ?
a. lorsque ces deux vecteurs sont parallèles ; b. lorsque ces deux vecteurs ne sont pas parallèles.

Réponse : b.

# Suites arithmético-géométriques

$u_{n+1} = a\,u_n + b$ avec $a \neq 1$.

1. Point fixe : $\ell = a\ell + b$, soit $\ell = \dfrac{b}{1-a}$.
2. $v_n = u_n - \ell$ est géométrique de raison $a$ : $v_n = a^n v_0$.
3. Donc $u_n = \ell + a^n(u_0 - \ell)$ ; si $\lvert a\rvert < 1$, $u_n \to \ell$.

Même idée pour une suite homographique : l'énoncé donne la suite auxiliaire géométrique.

Source : Fiches « Théorèmes de convergence », « Comparaisons asymptotiques » et TD4 (Moodle S1-MATHS-2031, Cours 4).

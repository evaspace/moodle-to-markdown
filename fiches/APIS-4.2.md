# Suite arithmétique

$u_{n+1} = u_n + r$ ; terme général $u_n = u_0 + nr = u_p + (n-p)r$.

Somme de termes consécutifs :
$$u_p + \dots + u_n = (n - p + 1)\,\frac{u_p + u_n}{2}, \qquad \sum_{k=0}^{n} k = \frac{n(n+1)}{2}$$

Source : Fiches « Théorèmes de convergence », « Comparaisons asymptotiques » et TD4 (Moodle S1-MATHS-2031, Cours 4).

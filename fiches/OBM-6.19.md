# Relations binaires : ordre et équivalence

Une relation $\mathcal{R}$ sur $E$ peut être :

- réflexive : $\forall x, x \mathcal{R} x$ ;
- symétrique : $x \mathcal{R} y \Rightarrow y \mathcal{R} x$ ;
- antisymétrique : $(x \mathcal{R} y \wedge y \mathcal{R} x) \Rightarrow x = y$ ;
- transitive : $(x \mathcal{R} y \wedge y \mathcal{R} z) \Rightarrow x \mathcal{R} z$.

**Équivalence** : réflexive, symétrique, transitive (classes d'équivalence). **Ordre** : réflexive, antisymétrique, transitive ; total si deux éléments sont toujours comparables.

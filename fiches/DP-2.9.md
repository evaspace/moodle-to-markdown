# Variable aléatoire et loi

Une variable aléatoire est une fonction $X : \Omega \to \mathbb{R}$. $X(\Omega) = \{x_1, \dots, x_n\}$ est l'ensemble de ses valeurs.

La loi de $X$ est donnée par $X(\Omega)$ et les valeurs $P(X = x_i)$, avec $\sum_i P(X = x_i) = 1$.

Fonction de répartition : $F_X(x) = P(X \leqslant x)$.

Source : Fiches de synthèse « Espace probabilisé », « Probabilités conditionnelles », « Variables aléatoires » (Moodle S1-MATHS-2031, Cours 2).

# Valeur moyenne d'une fonction

La valeur moyenne de $f$ continue sur $[a, b]$ ($a < b$) est
$$\mu = \frac{1}{b-a}\int_a^b f(x)\,dx$$
Le rectangle de base $[a, b]$ et de hauteur $\mu$ a la même aire algébrique que la courbe.

Source : Poly « S1 Cours Primitives Intégrales » et TD3 (Moodle S1-MATHS-2031, Cours 3).

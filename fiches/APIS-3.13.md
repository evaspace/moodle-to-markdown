# IPP : quel facteur dériver

- polynôme $\times$ $e^{x}$, $\sin$, $\cos$ : dériver le polynôme ($u = P$) ; une IPP par degré ;
- $\ln x$ seul ou polynôme $\times \ln x$ : dériver $\ln$ ($u = \ln x$), même avec $v' = 1$ : $\int \ln x\,dx = x\ln x - x$ ;
- $\arctan x$ : $u = \arctan x$, $v' = 1$ ;
- $e^{x}\sin x$, $e^{x}\cos x$ : deux IPP, on retrouve l'intégrale de départ et on résout l'équation (double IPP).

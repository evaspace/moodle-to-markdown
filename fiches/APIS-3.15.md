# Se ramener à arctan

$\int \dfrac{dx}{a^2 + x^2} = \dfrac{1}{a}\arctan\dfrac{x}{a}$ (poser $x = at$).

Pour $\dfrac{1}{x^2 + px + q}$ sans racine réelle : forme canonique $(x + \frac{p}{2})^2 + c^2$, puis changement de variable affine $t = \dfrac{x + p/2}{c}$ pour obtenir $\dfrac{1}{c}\arctan t$.

Source : Poly « S1 Cours Primitives Intégrales » et TD3 (Moodle S1-MATHS-2031, Cours 3).

# Suite numérique : définition

Une suite réelle est une application $u : \mathbb{N} \to \mathbb{R}$, notée $(u_n)_{n \in \mathbb{N}}$ ; $u_n$ est le terme de rang $n$.

- Définition explicite : $u_n = f(n)$ (ex. $u_n = \frac{n}{n+3}$).
- Définition par récurrence : $u_0$ donné et $u_{n+1} = f(u_n)$ (voir [APIS-4.14](/cours/fiches/APIS-4.14)).

# Suite géométrique et somme géométrique

$u_{n+1} = q\,u_n$ ; terme général $u_n = u_0\,q^n = u_p\,q^{n-p}$.

Pour $q \neq 1$ :
$$\sum_{k=0}^{n} q^k = \frac{1 - q^{n+1}}{1 - q}, \qquad u_p + \dots + u_n = u_p\,\frac{1 - q^{n-p+1}}{1 - q}$$
Limite de $q^n$ : voir [APIS-4.8](/cours/fiches/APIS-4.8).

Source : Fiches « Théorèmes de convergence », « Comparaisons asymptotiques » et TD4 (Moodle S1-MATHS-2031, Cours 4).

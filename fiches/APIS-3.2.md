# Primitives usuelles

| $f(x)$ | $F(x)$ | intervalle |
|---|---|---|
| $x^n$, $n \in \mathbb{N}$ | $\frac{x^{n+1}}{n+1}$ | $\mathbb{R}$ |
| $x^\alpha$, $\alpha \neq -1$ | $\frac{x^{\alpha+1}}{\alpha+1}$ | $]0, +\infty[$ |
| $\frac{1}{x}$ | $\ln\lvert x\rvert$ | $]-\infty,0[$ ou $]0,+\infty[$ |
| $\frac{1}{\sqrt{x}}$ | $2\sqrt{x}$ | $]0, +\infty[$ |
| $e^x$ | $e^x$ | $\mathbb{R}$ |
| $\cos x$ | $\sin x$ | $\mathbb{R}$ |
| $\sin x$ | $-\cos x$ | $\mathbb{R}$ |
| $1 + \tan^2 x = \frac{1}{\cos^2 x}$ | $\tan x$ | $]-\frac{\pi}{2}, \frac{\pi}{2}[$ |
| $\frac{1}{1+x^2}$ | $\arctan x$ | $\mathbb{R}$ |

Linéarité : une primitive de $af + bg$ est $aF + bG$.

Source : Poly « S1 Cours Primitives Intégrales » et TD3 (Moodle S1-MATHS-2031, Cours 3).

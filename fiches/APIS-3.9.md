# Linéarité, relation de Chasles, parité

- Linéarité : $\int_a^b (\lambda f + \mu g) = \lambda \int_a^b f + \mu \int_a^b g$.
- Chasles : $\int_a^b f = \int_a^c f + \int_c^b f$.
- $\int_b^a f = -\int_a^b f$.
- $f$ paire : $\int_{-a}^{a} f = 2\int_0^a f$ ; $f$ impaire : $\int_{-a}^{a} f = 0$.

Exemple : $\int_{-1}^{2} \lvert x\rvert\,dx = \int_{-1}^0 (-x)\,dx + \int_0^2 x\,dx$.

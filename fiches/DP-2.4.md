# Probabilité conditionnelle

Si $P(B) \neq 0$, la probabilité de $A$ sachant $B$ est
$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$
$A \mapsto P(A \mid B)$ est une probabilité sur $\Omega$.

D'où $P(A \cap B) = P(A \mid B)\,P(B) = P(B \mid A)\,P(A)$.

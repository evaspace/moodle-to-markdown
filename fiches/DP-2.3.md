# Équiprobabilité

Si les évènements élémentaires sont équiprobables :
$$P(A) = \frac{\mathrm{Card}(A)}{\mathrm{Card}(\Omega)}$$
(« cas favorables sur cas possibles »). Le calcul se ramène à du dénombrement.

Exemple : deux dés équilibrés, $\mathrm{Card}(\Omega) = 36$, $P(\text{somme} = 7) = 6/36$.

Source : Fiches de synthèse « Espace probabilisé », « Probabilités conditionnelles », « Variables aléatoires » (Moodle S1-MATHS-2031, Cours 2).

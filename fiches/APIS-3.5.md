# Dérivée d'une composée et dérivées usuelles

$(g \circ u)' = u' \times (g' \circ u)$. Cas utiles :

- $(u^n)' = n u' u^{n-1}$, $(\sqrt{u})' = \dfrac{u'}{2\sqrt{u}}$, $\left(\dfrac{1}{u}\right)' = -\dfrac{u'}{u^2}$ ;
- $(e^u)' = u' e^u$, $(\ln u)' = \dfrac{u'}{u}$ ;
- $(\cos u)' = -u' \sin u$, $(\sin u)' = u' \cos u$, $(\arctan u)' = \dfrac{u'}{1+u^2}$.

Produit et quotient : $(uv)' = u'v + uv'$, $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$.

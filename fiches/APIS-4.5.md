# Monotonie d'une suite

$(u_n)$ est croissante si $\forall n, u_{n+1} \geqslant u_n$, décroissante si $u_{n+1} \leqslant u_n$.

Méthodes :

- signe de $u_{n+1} - u_n$ ;
- si $u_n > 0$ : comparer $\dfrac{u_{n+1}}{u_n}$ à $1$ (produits, factorielles, puissances) ;
- si $u_n = f(n)$ : variations de $f$ sur $[0, +\infty[$ ;
- suite récurrente : récurrence.

Source : Fiches « Théorèmes de convergence », « Comparaisons asymptotiques » et TD4 (Moodle S1-MATHS-2031, Cours 4).

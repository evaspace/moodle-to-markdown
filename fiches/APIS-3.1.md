# Primitive : définition

$F$ est une primitive de $f$ sur l'intervalle $I$ si $F$ est dérivable sur $I$ et $F' = f$.

- Toute fonction continue sur $I$ admet une primitive sur $I$.
- Si $F$ est une primitive de $f$, les primitives de $f$ sont les $F + C$, $C \in \mathbb{R}$.
- Imposer $F(x_0) = y_0$ donne une unique primitive.

Source : Poly « S1 Cours Primitives Intégrales » et TD3 (Moodle S1-MATHS-2031, Cours 3).

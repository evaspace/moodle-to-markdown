# Démonstrations de cours sur les suites

À savoir refaire :

- **Convergente implique bornée** : avec $\varepsilon = 1$, $\exists N, \forall n \geqslant N, \lvert u_n\rvert \leqslant \lvert\ell\rvert + 1$ ; on prend $M = \max(\lvert u_0\rvert, \dots, \lvert u_{N-1}\rvert, \lvert\ell\rvert + 1)$.
- **Gendarmes** : pour $\varepsilon > 0$, à partir d'un rang $\ell - \varepsilon \leqslant v_n \leqslant u_n \leqslant w_n \leqslant \ell + \varepsilon$.
- **Unicité de la limite** : par l'absurde avec $\varepsilon = \frac{\lvert\ell - \ell'\rvert}{3}$.

Source : Fiches « Théorèmes de convergence », « Comparaisons asymptotiques » et TD4 (Moodle S1-MATHS-2031, Cours 4).
